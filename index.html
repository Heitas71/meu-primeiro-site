Aula 1 — O que é HTML?

HTML é a linguagem usada para organizar o conteúdo de uma página da internet.

Com HTML, podemos criar títulos, parágrafos, imagens, links e listas.

Exemplo de HTML:


<h1>Olá, mundo!</h1>
<p>Este é meu primeiro parágrafo.</p>

O que esse código faz?

A tag h1 cria um título principal. A tag p cria um parágrafo.

Aula 2 — Conhecendo as tags HTML

As tags são elementos que usamos para organizar o conteúdo de uma página.

Veja algumas das principais tags:

  • h1: cria um título principal.
  • h2: cria um subtítulo.
  • p: cria um parágrafo.
  • img: adiciona uma imagem.
  • a: cria um link.
  • ul: cria uma lista.

Exemplo prático:


<h1>Meu primeiro site</h1>
<p>Estou aprendendo HTML!</p>

Cada tag possui uma função. Combinando várias tags, conseguimos construir páginas completas.

Aula 3 — Como criar links em HTML

Os links permitem navegar de uma página para outra ou acessar outros sites.

Exemplo prático:


<a href="https://www.google.com">
    Acessar o Google
</a>

Como funciona?

A tag a cria o link. O atributo href indica o endereço para onde o visitante será levado.

O texto entre as tags será a parte clicável.

Aula 4 — Como adicionar imagens em HTML

Podemos adicionar imagens a uma página usando a tag img.

Exemplo prático:


<img src="imagem.jpg" alt="Descrição da imagem">

Como funciona?

O atributo src indica o caminho da imagem. Já o atributo alt apresenta uma descrição da imagem caso ela não seja exibida.

A tag img não precisa de uma tag de fechamento.

Aula 5 — Como criar listas em HTML

As listas servem para organizar informações em uma página.

Lista não ordenada:


<ul>
    <li>Maçã</li>
    <li>Banana</li>
    <li>Laranja</li>
</ul>

A tag ul cria uma lista com marcadores. A tag li representa cada item da lista.

Lista ordenada:


<ol>
    <li>Primeiro passo</li>
    <li>Segundo passo</li>
    <li>Terceiro passo</li>
</ol>

A tag ol cria uma lista numerada.

Aula 6 — Como criar tabelas em HTML

As tabelas permitem organizar informações em linhas e colunas.

Exemplo prático:


<table>
    <tr>
        <th>Nome</th>
        <th>Idade</th>
    </tr>

    <tr>
        <td>Pedro</td>
        <td>14</td>
    </tr>
</table>

Como funciona?

A tag table cria a tabela. A tag tr cria uma linha. A tag th cria uma célula de cabeçalho. A tag td cria uma célula comum.

Aula 7 — Como organizar uma página HTML

Uma página HTML possui diferentes partes. Cada uma delas tem uma função.

Principais elementos:

  • header: cabeçalho da página.
  • nav: área de navegação.
  • main: conteúdo principal.
  • section: seção de conteúdo.
  • footer: rodapé da página.

Exemplo prático:


<header>
    Meu site
</header>

<nav>
    Menu de navegação
</nav>

<main>
    Conteúdo principal
</main>

<footer>
    Rodapé do site
</footer>

Organizar o HTML facilita a leitura, a manutenção e o desenvolvimento de um site.

Aula 8 — Introdução ao CSS

CSS é a linguagem utilizada para definir a aparência de uma página HTML.

Com CSS, podemos mudar cores, tamanhos, fontes, espaçamentos e posicionamentos.

Exemplo prático:


h1 {
    color: blue;
    font-size: 30px;
}

Como funciona?

O seletor h1 indica qual elemento será estilizado. A propriedade color altera a cor do texto. A propriedade font-size altera o tamanho da fonte.

O CSS permite transformar uma página simples em um site visualmente organizado e bonito.

Aula 9 — Como conectar o CSS ao HTML

Para aplicar os estilos do CSS em uma página HTML, precisamos conectar os dois arquivos.

Exemplo prático:


<head>
    <link rel="stylesheet" href="estilo.css">
</head>

Como funciona?

A tag link conecta o arquivo CSS ao HTML. O atributo rel informa que estamos utilizando uma folha de estilos.

O atributo href indica o nome ou caminho do arquivo CSS.

Assim, as alterações feitas no CSS podem modificar a aparência da página HTML.

Aula 10 — Cores e fundos com CSS

O CSS permite alterar as cores dos textos e os fundos dos elementos de uma página.

Exemplo prático:


body {
    background-color: black;
}

h1 {
    color: blue;
}

p {
    color: white;
}

Como funciona?

A propriedade background-color altera a cor do fundo.

A propriedade color altera a cor do texto.

Podemos utilizar nomes de cores ou códigos de cores, como #38bdf8.

Aula 11 — Fontes e tamanhos de texto com CSS

O CSS permite modificar a aparência dos textos, deixando a página mais organizada e fácil de ler.

Principais propriedades:

  • font-family: altera o tipo da fonte.
  • font-size: altera o tamanho do texto.
  • font-weight: altera a espessura da fonte.
  • text-align: altera o alinhamento do texto.

Exemplo prático:


h1 {
    font-family: Arial, sans-serif;
    font-size: 32px;
    font-weight: bold;
    text-align: center;
}

Como funciona?

Essas propriedades permitem controlar o estilo dos textos de uma página.

Aula 12 — Espaçamentos com CSS

O CSS permite controlar os espaços internos e externos dos elementos.

Principais propriedades:

  • margin: cria espaço externo.
  • padding: cria espaço interno.

Exemplo prático:


section {
    margin: 20px;
    padding: 30px;
}

Como funciona?

Margin cria uma distância entre um elemento e os elementos ao seu redor.

Padding cria uma distância entre o conteúdo e a borda do próprio elemento.

Aula 13 — Bordas e cantos arredondados com CSS

O CSS permite adicionar bordas aos elementos e modificar o formato de seus cantos.

Principais propriedades:

  • border: adiciona uma borda.
  • border-radius: arredonda os cantos.

Exemplo prático:


section {
    border: 2px solid blue;
    border-radius: 12px;
}

Como funciona?

A propriedade border define a espessura, o estilo e a cor da borda.

A propriedade border-radius controla o arredondamento dos cantos.

Aula 14 — Como organizar arquivos de um site

Um site pode possuir vários arquivos. Organizá-los corretamente facilita o desenvolvimento.

Exemplo de organização:


meu-site/
│
├── index.html
├── estilo.css
│
└── imagens/
    ├── foto1.jpg
    └── foto2.png

Para que serve cada arquivo?

  • index.html: contém a estrutura da página.
  • estilo.css: controla a aparência do site.
  • imagens: guarda as imagens utilizadas.

Manter os arquivos organizados ajuda a evitar erros e facilita futuras alterações.
