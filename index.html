Aula 1 — O que é HTML?

HTML é a linguagem usada para organizar o conteúdo de uma página da internet.

Com HTML, podemos criar títulos, parágrafos, imagens, links e listas.

Exemplo de HTML:


<h1>Olá, mundo!</h1>
<p>Este é meu primeiro parágrafo.</p>

O que esse código faz?

A tag h1 cria um título principal. A tag p cria um parágrafo.
